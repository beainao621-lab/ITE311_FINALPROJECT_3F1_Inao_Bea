# FlorisTrack: Web-Based Flower Shop Management and Custom Ordering System

**Student Name:** Bea Inao
**Course and Section:** Web System and Technologies 2 - 3F1

## Project Description
FlorisTrack is a web-based system for managing a flower shop. It lets customers browse flowers and place custom bouquet orders, while the shop owner manages products, orders, and inventory.

## Technologies Used
- HTML, CSS, JavaScript
- PHP
- MySQL
- Git and GitHub
